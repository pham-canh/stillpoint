Stillpoint

Camera and data

Stillpoint is a two-minute, camera-only breathing experience. This page explains exactly what happens to your camera frames and the measurements derived from them.

The short version: frames are measured in memory on this computer, never recorded, never uploaded, and discarded when the session ends. The only network request is the Presage SDK authenticating your API key. SDK telemetry is disabled.

What the camera sees

In the default mode, the local Stillpoint process opens the camera only after you tick the consent box and press Begin. It captures video at up to 1280×720 with the SDK's native useCamera() path. Frames stay inside that process for measurement; they are not written to disk or uploaded. No browser camera permission prompt is needed in this mode.

A downsampled 320×240 preview is sent over a loopback WebSocket so you can position yourself: face and upper chest in frame, even light, camera still. You can hide the preview during a session without stopping the measurement.

If the server cannot access a camera, the optional CAPTURE_MODE=frames fallback lets the browser capture and send 640×480 RGBA frames over loopback instead. In that mode the browser's camera prompt is a second, independent consent.

Where processing happens

The Presage SmartSpectra SDK runs natively inside the local Stillpoint process. It estimates pulse rate, breathing rate, and HRV directly from the camera. Expression analysis is optional and off by default; if you enable it, the scene's colors can follow that estimate. With it off, the SDK is not asked for the expression metric at all. Stillpoint requests only these four signals, not traces, landmarks, blinking, or talking.

Derived measurements stay in memory. The browser also receives them over a local server-sent-events connection so the interface can show pulse, breathing, and HRV in real time.

What leaves this machine

Camera frames and measurements do not leave this machine. Stillpoint does not send them to Presage. The SmartSpectra SDK contacts Presage to authenticate the API key and verify the subscription, and may obtain its model or update files; those requests do not include Stillpoint's frames or measurements. SDK telemetry is explicitly disabled in code (enableTelemetry: false). Stillpoint has no analytics, advertising, accounts, or third-party AI services, and the page loads no external scripts, fonts, or images.

Storage, retention, and deletion

  • No frames are written to disk, buffered in a file, or stored in a database.
  • No measurements are logged or persisted by Stillpoint.
  • Frames are dropped immediately after they are handed to the SDK.
  • Measurements are discarded when the session ends or the tab closes.
  • Stopping a session releases the camera and closes the local connections.
  • If you set the optional DEMO_VIDEO server variable, a local clip you chose is read by the SDK instead of a camera; it is not uploaded either.

Consent and control

Nothing starts until you tick the consent checkbox. In the default native mode the local Stillpoint process opens the camera only after Begin; the browser does not request camera access. In the frames fallback, the browser prompt is a second, independent consent. You can stop at any time with the Stop button or the Escape key; hiding the tab also ends the session. The camera is released when the session ends.

Sharing and third parties

Stillpoint does not share frames or measurements with anyone. The only third party involved is Presage, which validates the API key used by the SDK. There are no optional AI services, no cloud inference, and no remote logging.

Security boundaries

The Stillpoint server binds to loopback only (127.0.0.1 by default), rejects cross-origin WebSocket and control requests, and sets a strict Content Security Policy. The app is designed to be opened at http://127.0.0.1:4317 or http://localhost:4317. In native mode the server process owns the camera; the browser-facing camera policy is used only by the frames fallback.

Wellness, not medicine

SmartSpectra metrics are for general wellness and informational purposes. They are not FDA-cleared and are not a diagnosis or treatment. Stillpoint does not provide medical advice, make medical decisions, or monitor anyone covertly.

Stillpoint is an open-source entry for the Presage SmartSpectra SDK Challenge. Read the source at the public repository linked from the submission post, or contact the maintainer through the repository issues.
