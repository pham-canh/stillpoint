## Reproduce the pacer trace

From the repository root:

```bash
node --input-type=module -e "
import { Pacer } from './public/lib/pacer.js';
function trace(bpm, label) {
  const p = new Pacer();
  p.setMeasuredRate(bpm);
  p.begin(0);
  const rows = [{ breath: 0, period: p.periodMs / 1000 }];
  let now = 0;
  for (let cycle = 1; cycle <= 10; cycle += 1) {
    now += p.periodMs;
    const t = p.tick(now);
    rows.push({ breath: t.breaths, period: +(t.periodMs / 1000).toFixed(3) });
  }
  return { label, bpm, measured: +(60 / bpm).toFixed(2), rows };
}
console.log(JSON.stringify([trace(7.7, '7.8 s'), trace(13.3, '4.5 s')], null, 2));
"
```

The trace shows the behaviour the tests assert: the guide period only increases toward 10 s (it
never goes below the natural period), and a natural period in the 10–12 s range is held.

## Reproduce the frames

The demo video is not stored in this repository. With the recording at `stillpoint-demo-cfr.mp4`:

```bash
ffmpeg -ss 20  -i stillpoint-demo-cfr.mp4 -frames:v 1 stillpoint-settle.png
ffmpeg -ss 137 -i stillpoint-demo-cfr.mp4 -frames:v 1 stillpoint-summary.png
```

The permissions and consent for the person in the frame are covered by the post's "Demo video" note.
